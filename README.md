# 🏆 WSports
### With Sports, We Sports
**아마추어 스포츠 경기 매칭 웹 서비스**

> 아마추어 스포츠 경기에서 부족한 인원이나 상대 팀을 원하는 조건에 맞게 찾아주는 통합 매칭 서비스입니다.

---

## 📌 프로젝트 소개

WSports는 아마추어 스포츠 참여자들이 원하는 경기와 상대 팀을 쉽게 찾고, 경기 참여부터 팀 관리, 경기 후기 공유까지 이용할 수 있도록 제작한 스포츠 매칭 웹 서비스입니다.

사용자는 개인 경기 및 팀 경기를 모집하고 신청할 수 있으며, 마이페이지에서 자신의 경기 활동 내역과 알림을 관리할 수 있습니다.

### 🎯 프로젝트 목표
- 아마추어 스포츠 경기 매칭의 접근성 향상
- 개인 및 팀 단위 경기 모집과 참여 편의성 제공
- 경기 신청 및 활동 내역의 통합 관리
- 경기 후기 공유를 통한 사용자 간 소통 활성화

## 💻 My Responsibilities

### 마이페이지 · 알림 관리 · 후기 게시판

WSports 프로젝트에서 마이페이지와 경기 후기 게시판을 담당했습니다.

개인·팀 경기 활동 내역 조회, 관심 경기 및 가입 신청 관리, AJAX 기반 알림 처리, 후기 게시판 CRUD와 댓글·좋아요 기능을 구현하는 업무를 담당했습니다.

### 01. 👤 마이페이지 (My Page)

**개인 경기 내역 관리**
- 참가한 개인 경기 목록 조회
- 내가 생성한 경기 목록 조회 및 모집 상태 확인
- 월별·종목별·상태별 경기 내역 필터링
- 관심 개인 경기 목록 조회 및 등록·해제
- 경기 상세 정보 및 참가자 목록 이동
- 종료된 경기의 후기 작성 페이지 연동

**팀 및 가입 신청 관리**
- 가입한 팀 목록 조회
- 팀 가입 신청 내역 조회
- 가입 팀 및 가입 신청 탭 분리 관리
- 대기 중인 팀 가입 신청 취소
- 팀 상세 정보 및 팀 관리 페이지 연동

**팀 경기 활동 관리**
- 소속 팀의 경기 참여 내역 조회
- 월별·팀별·종목별·상태별 경기 필터링
- 상대 팀 정보 및 참가 팀 목록 조회
- 팀 경기 상세 정보 조회
- 경기 종료 후 출석 및 상대 팀 평가 화면 연동
- 종료된 팀 경기의 후기 작성 연동

**내가 작성한 후기 관리**
- 작성한 후기 목록 조회
- 페이지네이션 적용
- 후기 상세 조회 및 수정
- 본인이 작성한 후기 삭제
- 논리 삭제(Soft Delete) 방식 적용

### 02. 🔔 알림 관리 (Notification)

- 사용자별 알림 목록 조회
- 알림 제목, 내용 및 읽음 상태 표시
- 개별 알림 읽음 처리
- 전체 알림 읽음 처리
- AJAX 기반 비동기 알림 처리
- 알림 클릭 시 Target URL을 통한 관련 페이지 이동

### 03. 📝 경기 후기 게시판 (Review Board)

**게시글 관리**
- 경기 후기 목록 조회 및 최신순 정렬
- 경기별 후기 모아보기
- 키워드 및 종목별 검색
- 페이지네이션 적용
- 게시글 작성·조회·수정·삭제(CRUD)
- 작성자 본인 확인 및 수정·삭제 권한 관리
- 논리 삭제(Soft Delete) 적용

**좋아요 및 댓글 관리**
- 후기 좋아요 등록 및 해제
- 게시글별 댓글 목록 조회
- 로그인 사용자 댓글 작성
- 본인이 작성한 댓글 삭제
- AJAX를 활용한 좋아요 및 댓글 처리

### 04. 🧭 공통 UI 및 페이지 연동

- 마이페이지 공통 사이드바 JSP 구성
- JSP Include를 활용한 공통 메뉴 관리
- 마이페이지 메뉴별 화면 이동 및 URL 연동
- 개인 경기, 팀 경기, 알림 및 후기 메뉴 연결
- 신고·문의, 정산 및 결제 내역 관련 메뉴 연동

## 🏗️ 시스템 아키텍처

**MVC2 패턴 기반 웹 애플리케이션**

```text
       사용자 (Client)
              |
              ▼
      JSP / HTML / CSS
              |
              ▼
       JavaScript / AJAX
              |
              ▼
       Servlet Controller
              |
              ▼
         MyBatis DAO
              |
              ▼
          MariaDB
```

- View: JSP 기반 사용자 화면
- Controller: Servlet 기반 요청 및 흐름 제어
- Model: DAO 및 MyBatis 데이터 처리
- Database: MariaDB 데이터 저장 및 조회
- AJAX: 비동기 통신을 통한 데이터 처리
